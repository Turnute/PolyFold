# PolyFold


## Présentation du projet

PolyFold est un projet qui consiste à développer un jeu de réflexion autour du dépliement de polycubes. Le joueur doit déplier progressivement les faces d'un objet 3D pour obtenir un patron en 2D, sans superposition. 

Le jeu est développé avec Godot.
